# RTL、仿真与跨时钟域

## 设计前的约定

登记顶层和源文件顺序、HDL 标准、参数组合、时钟频率、复位极性/同步策略。每个寄存器明确驱动时钟与复位；同一状态避免多进程驱动。顺序逻辑采用与语言语义相符的非阻塞赋值，组合逻辑覆盖所有分支以避免非预期锁存器。VHDL 使用对应语言规则，不机械套用 Verilog 语法。

可综合逻辑不借仿真延时构造硬件，不通过关闭告警掩盖未知值或多驱动。初始化、存储器推断、算术 IP 和 HDL 特性按目标工具支持确认；保留参数边界（计数为 1、深度非 2 次幂、零/最大输入）行为。

定点运算注明总位宽、符号位和小数位，推导乘加中间宽度，明确定宽扩展、截位、舍入、饱和或回绕。参考模型与 RTL 比较按协议与时钟周期对齐，不只比较最终均值。

## 时钟、复位与 CDC

- 优先使用时钟使能实现低速动作；新时钟经目标器件支持的专用资源产生并登记约束，不能随意拿普通逻辑组合输出作时钟。
- 复位选择按架构和目标器件要求说明；若异步置位复位，通常需在每个目标时钟域同步释放并核对启动顺序。PLL 锁定、时钟缺失与复位期间的输出应有明确策略，不随意给所有数据通路添加复位而破坏存储器推断。
- 稳定单比特电平可考虑目标域同步链，级数、属性及可靠性按厂商方法确认；不能把“两级寄存器”当成适合所有信号的保证。
- 窄脉冲/事件需握手、toggle 或协议保证；普通同步链可能漏脉冲。多位数据需一致性协议、稳定数据握手或异步 FIFO；不能逐位同步后认为总线一定一致。
- Gray 指针/FIFO 仍需正确结构、复位与物理时序约束；异步路径的时序例外不等于 CDC 已解决。根据选定厂商文档检查 skew/延迟要求与例外优先级。
- 不用大范围 false path 或 asynchronous clock group 隐藏未解释的路径。每个例外记录起点、终点、协议证据、理由和复核者。相关时钟也可能因例外需要 CDC 处理。

## 有判定结果的 testbench

每个关键模块至少覆盖正常、边界、复位及与其协议相关的失败场景；选择能发现错误的用例，不机械为每行代码造测试。包括背压/停顿、FIFO 空满、帧中复位、溢出、超时、参数边界等适用场景。

自检输出可判定 PASS/FAIL，失败返回非零或可被运行脚本可靠识别，包含超时终止。固定/记录随机种子；保存命令、测试输入、摘要和有用波形。testbench 的驱动/采样时刻要避免竞态。

行为仿真验证数字行为，不模拟证明亚稳态安全或板上电气兼容。只有在需求/故障需要时追加门级、带延迟或功耗仿真；不要求对所有小改动运行无关的大套验证。

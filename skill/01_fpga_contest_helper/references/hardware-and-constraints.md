# 板卡、引脚、约束与首次上板

## 先对齐同一块实物

检索现有照片、原理图和板卡手册。分别记录板卡名称/PCB 版本、器件完整料号/封装、下载器、跳帽/拨码和文档版本。相似外观、网店标题和 FPGA 系列名不能代替完整型号。

接线使用“板卡编号 + 接口/针号 → 模块端子”，记录观察方向、Pin 1、电平、方向和参考地；线色仅作辅助。用户纠正硬件理解后保存原假设、纠正证据、新结论和受影响文件，不在后续又恢复旧假设。

核对供电输入范围、Bank VCCIO、I/O standard、外设电平与上拉来源，必要时做电平转换。不能默认 FPGA 管脚容忍 5 V，也不能仅凭外设供电推定其信号电平。隔离系统按原设计处理参考地，不强行跨隔离接地。

## 约束分层

| 类别 | 必须有的依据 |
| --- | --- |
| 物理引脚 | 当前 PCB 原理图、完整封装管脚、端口名、差分对、专用时钟引脚 |
| 电气 | Bank 电压、I/O 标准、驱动/转换速率、上下拉及外接负载 |
| 时钟 | 真实输入频率/周期、源与派生关系、工具识别情况、必要不确定度 |
| 外部接口时序 | 对端手册、时钟关系、板级延迟预算，输入/输出 min/max 场景 |
| 时序例外 | 功能或 CDC 依据、准确作用范围、没有吞掉正常需分析的路径 |

资料不足就列未决项，先写端口规格而非生效约束。不要把示例 PIN、50 MHz、LVCMOS33 当通用默认。板卡不同版本不得混用 XDC/SDC/QSF/CST 等文件；语法和命令按已安装工具确认。

## 上板顺序

断电检查与接线→按厂家说明限流供电/核对电源→识别下载链和器件→最小时钟/复位/LED 或可观测输出→单个 I/O/接口→系统级集成。下载的最小设计也须目标器件和约束正确。

涉及电机或外部功率时先停机/失能、空载或架空、限输出，再加负载；纯 FPGA 数字项目不强制加入小车特有步骤。板卡灯亮、下载完成、USB 被识别分别只证明对应事实。

片上逻辑分析仪记录采样域、触发、探针、捕获文件和构建身份；添加调试核会改变资源与时序，重新实现并复核。移除调试核后的最终版也重新验证，不能拿调试版报告代替。

JTAG/SRAM 易失性配置与 Flash 固化是不同实验。先核对目标器件/配置存储器、模式和当前文件身份，再按用户任务执行；Flash 擦写涉及现有镜像时说明范围并确认可回退状态。需要断电启动的交付必须实际验证重新上电。

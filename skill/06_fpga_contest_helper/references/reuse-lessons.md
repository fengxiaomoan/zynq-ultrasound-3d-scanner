# 从电赛迁移了什么

来源为已有电赛助手与 2026 H 题复盘，以及 2026-09-22 用户对协作的反馈；这里抽象为方法，不携带旧工程源码或私人历史。

| 电赛经验 | FPGA 项目中的落实 |
| --- | --- |
| 接线指导有用，但部分硬件理解曾需用户纠正 | 原理图、实物和端子映射相互核对；纠正写入 BOARD，旧假设显式废弃 |
| 改程序后实际烧录的仍可能是旧产物 | 绑定 RTL/约束/IP、构建日志、bitstream 哈希、下载路径和运行版本 |
| 独立诊断工程便于定位 | 模块自检 testbench + 已核对约束的最小上板工程 |
| 全系统旧 HEX 回退会撤销其他功能 | 单模块在当前系统副本回退，重新生成 bitstream 并回归 |
| 单次成功和现场稳定性存在差距 | 将边界、重启、重复试次和全过程测量纳入验收，不臆测旧比赛失分根因 |
| 交接过大容易混淆历史与当前 | 根目录只留活动状态，JSONL 与原始证据按任务归档 |
| 人与助手需要看到同一套实验条件 | 记录板卡版本、Bank 电压、时钟/复位、实际产物和测量位置 |

不继承：MSPM0/STM32 优先级、H 题专用引脚、四位数码计时、轮胎/舵机步骤、旧成功率、旧赛程、MCU C 工程目录、冻结固件。仅当新题确有对应需求时重新设计并验证。

新增的 FPGA 内容：RTL 并发与协议、时钟/复位域、CDC、位宽与定点误差、吞吐和延迟、时序约束覆盖、实现报告、配置方式与片上调试。它们是工程指导，不冒充赛事规定。

这份 skill 独立于原 electronics-contest-helper，名称为 fpga-contest-helper，避免旧 MCU 触发条件与新 FPGA 任务混用；原 skill 保留供后续电赛项目使用。

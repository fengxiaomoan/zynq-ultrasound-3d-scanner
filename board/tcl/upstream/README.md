# 原始上板脚本（仅参考）

这里的 Tcl 是项目现场使用的原始版本。仓库中已把本机绝对路径替换为 `<repo-root>`，其余内容保持原样，用于对照“当时怎么跑、怎么取证”。

**不要直接在新机器上执行**：

- 路径指向早期工程 `fpga_ps_m2` / `fpga_ps_m3`，本仓库没有这些构建目录；
- `acquire*.tcl` 依赖 `fpga_dsp_v2` 的 ltx 与早期 `live_run` 目录；
- `m3_load_once/retry` 依赖早期的 `fpga_ps_m3` 路径。

要复现，请用上一级的：

- `../load_m3_pkg.tcl`：加载包内 M3 位流 + 固件；
- `../m2b_scan.tcl`：驱动电机（已改成包内路径）。

保留这些文件的价值是：当报告里说“当时用 `mwr -bin` 而不是 `dow`”“当时 `-nolog` 压掉了日志”，可以回到原始脚本核对。
